# Sign up and set up your clinic

Create your Dentalemon account and name your clinic. You only do this once.
{ .meta }

**Time:** about 2 minutes · **You'll need:** an email address you can use for work.
{ .meta }

## Before you start

- Use the email you want to sign in with every day. You can't change it later in the app yet.
- **Invite code** is marked **Coming soon**. Leave that box empty.

## Steps

### 1. Open the sign-up page

Open Dentalemon and tap **Sign up** under the sign-in box.

You should see: **Create your account**, with boxes for your name, email and password.
{ .see }

![The Create your account page with empty Full name, Email, Password, Confirm password and Invite code boxes; Invite code is marked Coming soon](../assets/sign-up-and-clinic-setup/01-create-account.webp)

### 2. Fill in your details

1. **Full name**: your name as patients know you, for example *Ana Santos*.
2. **Email**: your work email.
3. **Password**: at least 8 characters. A green check appears next to **At least 8 characters** when it's long enough.
4. **Confirm password**: type the same password again.
5. **Invite code (optional)**: marked **Coming soon**. Leave it empty.

You should see: every box filled in and the password rule checked.
{ .see }

![The Create your account form filled in for Ana Santos, with the password rule checked](../assets/sign-up-and-clinic-setup/02-account-filled.webp)

### 3. Create your account

Tap **Create account**.

You should see: **Welcome to Dentalemon, *your name*!** and a **Let's get started** button.
{ .see }

![The welcome screen: Welcome to Dentalemon, Ana Santos! with a Let's get started button](../assets/sign-up-and-clinic-setup/03-welcome.webp)

### 4. Get started

Tap **Let's get started**.

You should see: **Set up your clinic**, with an empty **Clinic name** box.
{ .see }

### 5. Name your clinic

Type your clinic's name in **Clinic name**.

You should see: your clinic name in the box, and a **Create clinic** button.
{ .see }

![The Set up your clinic box with Lemon Tree Dental typed in and a Create clinic button](../assets/sign-up-and-clinic-setup/05-clinic-filled.webp)

### 6. You're in

Tap **Create clinic**. Dentalemon opens **Home**. A new clinic has no patients or visits yet, so the cards are empty. They fill up as you work.

You should see: a greeting with your first name at the top (**Good morning**, **Good afternoon** or **Good evening**, by the time of day), and the sidebar on the left: **Home**, **Appointments**, **Patients**, **Encounters**, **Orders**, **Cashier**, **Billing**, **Analytics** and **Notifications**.
{ .see }

![Home for a new clinic: the Good evening, Ana greeting card, an empty Total patient visits chart, and the sidebar](../assets/sign-up-and-clinic-setup/06-home-empty.webp)

## Tips

!!! tip "Finish your clinic details next"
    Add your clinic's address, phone and opening hours, and your price list, before you see patients.
    See [Settings basics](../clinic/settings-basics.md).

!!! warning "If something goes wrong"
    **You tap Create account and stay on the same page.** A box with a problem turns red and shows a message, such as **Passwords do not match.** or **Password must be at least 8 characters.**
    Fix that box and tap **Create account** again.

!!! info "Good to know"
    - Sign-up uses email and password only. There's no Apple or Google sign-in.
    - Invite codes aren't used yet. The box under **Invite code (optional)** says **Coming soon**.
    - **You can change this later** applies to the clinic name: you can rename it in **Settings › Clinic**.
